# EconomyPlugin

Paper 26.2 economy plugin (Java 25).

- `/bal [player]` - balance
- `/pay <player> <amount>`
- `/shop` - categories: Gear, Blocks, Food, Spawners, Potions (left-click buy 1, shift-click buy 16)
- `/tpa <player>`, `/tpahere <player>`, `/tpaccept`, `/tpdeny`
- `/give <username> <money>` - dev (Arv1oishated) and console only
- Sidebar shows your username and cash. New players start with $1,000.
